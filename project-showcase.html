1. Zandar AI — Autonomous AI Security & Multi-Agent Pentest Platform AI Cybersecurity · Multi-Agent System

An autonomous, operator-supervised cybersecurity engine designed to run end-to-end vulnerability assessments and authorized penetration testing loops. Built on a modular LangGraph StateGraph architecture that coordinates 18+ containerized security binaries (nmap, nuclei, ffuf, sqlmap, httpx, naabu, subfinder, hydra) isolated inside secure Docker runtime containers.

Features Amazon Bedrock Multi-Model Routing (Claude 3.5 Sonnet for tactical attack graph synthesis, DeepSeek/Qwen for script generation), backed by a 3-tier GraphRAG long-term memory (Qdrant vector similarity + Neo4j infrastructure attack path graphs + PostgreSQL execution traces) with strict human-in-the-loop exploit authorization gates.

Hardened through an 11-agent, 5-dimension self-security-audit (prompt-injection, supply-chain, secret-leakage, authorization, agent-egress) synthesized via adversarial verification — 34 ranked findings surfaced, 10 resolved and re-verified including both Critical-severity issues, the remainder tracked by priority in a living report. Ships a bug-bounty submission mode (HackerOne/Bugcrowd-ready exports separating oracle-verified findings from unverified ones, an out-of-scope governance gate, and a Hacktivity duplicate-detection check), and is fully Docker-deployable — one docker compose up brings the backend, frontend, and five datastores to a verified healthy state.

Python LangGraph Docker (18+ Binaries) Amazon Bedrock GraphRAG (Qdrant+Neo4j) FastAPI Human-in-the-Loop Self-Audited Security (34 Findings) Bug-Bounty Export (HackerOne/Bugcrowd) One-Command Docker Deploy

2. Zandar OSINT — Multi-Tier Open-Source Intelligence & Verification Engine Data Engineering · NLP Intelligence

An enterprise-scale open-source intelligence aggregation and fact-checking platform. Implements 26 ingestion data adapters across 3 tiers (RSS feeds, GDELT global events, YouTube Data API, Google Play Store reviews, public Telegram channels, and Wayback Machine digital archives) running on a distributed Celery & Redis worker cluster.

Includes an IndoBERT hybrid sentiment & classification pipeline (RoBERTa-based open-source models, integrated and benchmarked against a human-labeled gold set), validated at 0.894 F1 Score on NusaX-Senti. Integrated with an automated claim verification pipeline that cross-references extracted claims against official government datasets (BPS & BMKG) for high-confidence intelligence synthesis.
